Open Source — 4 dự án công khai

Chúng tôi mở mã nguồn cốt lõi 30 ngày để cộng đồng dev Việt Nam có thể tham khảo, fork, học hỏi. Không phải vì marketing, mà vì tin Frugal Innovation lan tỏa nhanh hơn khi minh bạch.

Hardware

ecosyntech-pcb-v8

Open-source ESP32 industrial IoT gateway PCB. Wide-input 9-30V, MP1584 dual, WiFi+4G+LoRa, IP65 enclosure. CERN-OHL-S-2.0.

Firmware

ecosyntech-fw-v9-4

Secure offline-first ESP32 firmware. Multi-relay safety, 16MB OTA, HMAC + SemVer anti-rollback. PCB V8.0 ready. GPL-3.0.

Backend

ecosyntech-gas-v10-3

Apps Script backend 56 modules. HMAC auth, CSPRNG, multi-tier license, Aptos weekly anchor. Apache-2.0.

Web Local

ecosyntech-web-local-core

Offline-first Node.js backend. 100+ services, on-device AI/ML, multi-channel alerts, ISO 27001 aligned, Vietnamese SME-ready. AGPL-3.0.

Câu hỏi thường gặp

Farm OS có hoạt động khi mất mạng không?

Có. Đây là hệ điều hành offline-first. Khi mất mạng, thiết bị tiếp tục thu telemetry, điều khiển relay, lưu audit log local 16MB. Khi có mạng lại, tự sync về cloud — không mất dữ liệu.

1 người có vận hành được 100 thiết bị không?

Có. Hệ thống thiết kế cho founder solo + đội nhỏ. Tự diagnose + self-heal + alert Telegram + web admin tập trung. Pilot ghi nhận: 1 người quản lý ổn 100-150 thiết bị.

Source code có open-source không?

Có. 4 repo công khai trên GitHub ecosyntech68vn: PCB V8 (CERN-OHL), FW V9.4 (GPL-3.0), GAS V10.3 (Apache-2.0), Web Local Core (AGPL-3.0).
