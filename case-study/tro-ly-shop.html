Trợ Lý Shop — bot CSKH multi-tenant cho chủ shop nhỏ Việt Nam

Tóm tắt: Bot Telegram AI-first hỗ trợ chủ shop nhỏ chăm sóc khách 24/24. Multi-tenant (mỗi shop có catalog/đơn riêng), kiến trúc Flask + SQLite + AI skills modular. Vận hành bởi 1 founder. Test suite 24/24 PASS.

Bài toán

Chủ shop nhỏ Việt Nam (thời trang, F&B, làm đẹp) không đủ tiền thuê CSKH 24/7. Khách hỏi giá lúc 11 giờ đêm → không có ai trả lời → mất đơn.

Giải pháp

  • Multi-tenant Telegram bot: 1 instance bot hỗ trợ nhiều shop, mỗi shop tách dữ liệu hoàn toàn.
  • AI skills modular: skill `copywriter-viet-pro` viết câu trả lời tiếng Việt theo brand voice của shop; skill `order-tracker` quản lý đơn; skill `catalog-search` tìm sản phẩm.
  • Admin web UI: chủ shop xem/sửa câu trả lời AI, quản lý catalog qua dashboard Flask Jinja2.
  • Correction loop: khi AI trả lời sai, chủ shop sửa → câu sửa được lưu lại → AI học theo cho lần sau.

Stack kỹ thuật

  • Backend: Flask + SQLite (per-tenant) + Jinja2 templates
  • AI: Claude API (primary) + Gemini fallback gateway
  • Hosting: 1 VPS DigitalOcean $5-10/tháng (chạy chung với 2 bot khác: AI Thực Chiến + Cỗ Máy)
  • CI/CD: GitHub Actions — test 24 case pytest + py_compile + gitleaks secret scan
  • Source: Monorepo `All_In_One_ESTG` trên GitHub `ecosyntech68vn`

Kết quả định lượng (tính đến 31/05/2026)

  • 24/24 test case PASS trong CI
  • Latency trung bình: <1.5s từ tin nhắn khách đến reply AI
  • Cost vận hành: ~$8/tháng VPS + ~$5-15/tháng AI API tuỳ traffic
  • Stack maintainable bởi 1 người — toàn bộ codebase Python ~5000 LOC, đọc hiểu trong 1 buổi sáng

Bài học Frugal Innovation

  1. SQLite thay Postgres — multi-tenant per-file, đơn giản, backup = cp file.
  2. Jinja2 thay React — admin web UI cho non-tech user, không cần build step.
  3. 1 VPS chạy 3 bot — gộp deployment, share resources, giảm điểm hỏng.
  4. Skills modular — mỗi capability là 1 file Python độc lập, plug-and-play.

Không phù hợp khi

  • Shop yêu cầu integration với Shopify/WooCommerce/Magento (chưa hỗ trợ).
  • Volume >10.000 tin nhắn/ngày/shop (SQLite sẽ bottleneck — cần migrate Postgres).
  • Khách hàng cần SSO doanh nghiệp (chỉ hỗ trợ Telegram login hiện tại).
